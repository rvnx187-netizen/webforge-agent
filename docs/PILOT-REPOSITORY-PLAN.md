# Plano dos repositórios-piloto

## Repositório 1 — webforge-agent
Contém o prompt mestre, os modelos, os checklists, as lições generalizáveis e o changelog do método.

## Repositório 2 — webforge-demo-daymark
Contém a aplicação de exemplo criada para testar o WebForge em um projeto pequeno e de baixo risco.

## Regras de separação
- Não colocar o projeto Daymark dentro do repositório do agente.
- Não copiar arquivos ou segredos do ECHO/ECHO 2 para estes repositórios.
- As lições generalizáveis podem ser documentadas no WebForge; os defeitos específicos ficam no repositório do projeto.
- Os testes do Daymark devem ser executados antes de descrever o exemplo como validado.

## Estado
Os pacotes locais estão preparados. A criação dos repositórios remotos e o push dependem de o usuário criar os repositórios e autorizar a publicação.
